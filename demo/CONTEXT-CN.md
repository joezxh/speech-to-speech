# 语境术语表

本空间（space）的权威术语。这是一份术语表，而非规范——它定义词语的含义，而非任何东西的构建方式。请将设计 / 实现细节保留在 `DESIGN.md` 和代码中。

## 语音到语音 demo

产品：你通过点击球体并说话，与一个模型进行的语音对话。"本 demo" 和 "本 space" 指代同一事物。它运行在 Hugging Face 开放的 `speech-to-speech` 后端上。

## 流水线（pipeline）

一句话轮次所经过的有序路径，从你的声音到球体的回复。顺序是重要的——每一阶段消费上一阶段的输出：

`你说话 → VAD → STT → VLM → TTS → 球体回复`

- **VAD**——语音活动检测（voice activity detection）。决定*你何时*在说话，以便系统知道一个轮次已经开始和结束。模型：silero-vad。
- **STT**——语音转文本（speech to text）。把你的语音转写为文字。模型：nvidia/parakeet-tdt-1.1b。
- **VLM**——组成回复的视觉—语言模型（vision-language model）。通过 Cerebras 提供服务。模型：google/gemma-4-31B-it。
- **TTS**——文本转语音（text to speech）。用所选的 voice 把回复念出来。模型：Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice。

## 构建者（Builder）

在 about 面板中按 HF 用户名显示的、对创建该 space 有贡献的 Hugging Face 用户。当前的构建者有：tfrere、A-Mahla 和 andito。它不同于*模型*的作者（nvidia、google、Qwen、snakers4），模型作者按流水线阶段署名。

## 由……驱动（Powered by）

运行流水线的基础设施，在 about 面板中具名：Hugging Face Inference Endpoints（托管）和 Cerebras（LLM 推理）。它不同于 "built by"（人）和模型作者（训练每个模型的人）。

## 工具（Tool）

模型可以在对话中途调用的一个函数，用于完成流水线自身无法完成的事情（查点东西、看一眼摄像头）。工具在会话配置中声明给后端；模型自行决定何时调用它。它不同于始终运行的*流水线阶段*（VAD / STT / VLM / TTS）。

## 工具执行器（Tool executor）

当模型调用工具时，在客户端运行该工具并将结果返回后端的组件，以便模型能念出答案。它是往返缺失的那一半：后端已经发出调用，执行器运行它并回复。它不同于*工具*本身（被运行的东西）。

## 网络搜索工具（Web search tool）

一个为模型在网上查东西的工具。模型用一个查询调用它；工具执行器把查询转发给搜索代理，并将结果作为工具结果返回。仅在存在搜索密钥时激活。

## 摄像头快照工具（Camera snapshot tool）

一个让模型通过用户摄像头观看的工具。启用时，页面左下角显示一个实时自视图；当模型调用该工具时，执行器捕获一帧，并作为图像发送给模型，以便 VLM 能看到它。它不同于*预览*（用户看到的）和*快照*（发送给模型的单帧）。

## 搜索代理（Search proxy）

持有搜索密钥、并代表客户端调用外部搜索提供方的同源服务器路由（`/search`），因此密钥永远不会到达浏览器。它与页面位于同一个容器中。它不同于 *s2s 后端*（独立的负载均衡 speech-to-speech 服务）。

## 工具面板（Tools panel）

从右上角 "Tools" 按钮打开的对话框，每个工具一个开关（以及网络搜索密钥的状态）。打开 / 关闭一个开关，会在实时会话上声明或移除该工具。它不同于 *Settings*（连接、voice、指令）和 *About panel*（项目信息）。

## 身份块（Identity block）

顶栏左上角（取代旧的 wordmark）：demo 名称、一行简介，以及 "powered by" / "built by" 署名，直接展示而非藏在点击之后。

## 关于面板（About panel）

从身份块右侧的 (i) 图标打开的弹窗。包含对 speech-to-speech 项目的总体介绍（含仓库链接）和流水线。身份本身现在位于角落，而不在这里。

## 队列（Queue）

当所有计算资源都繁忙时，等待一个空闲对话槽位的用户队列。你加入队列，而不是被拒之门外；你通过到达队首或放弃而离开它。它不同于*会话*（一个真实的实时对话）——处于队列中尚未开始对话，等待所花的时间从不计入你的用量上限。

## 票据（Ticket）

你在队列中占据的位置。在加入时创建，demo 通过它告诉你所在位置和是否离开。票据不是会话：它只承诺一个排队位置，而非计算资源。

## 位置（Position）

队列中有多少人在你前面，等待时显示（"You're #3 in line"，你在队列第 3 位）。它只会递减。它不同于*预计等待时间*——demo 显示位置，从不显示时间，因为等待时间不可预测。

## 认领（Claim）

你到达队首、一个空闲槽位归你所有的那一刻——队列交接给一个真实的会话，对话开始。这也是你的用量上限首次开始生效的点（等待期间从不生效）。

## 已满载（At capacity）

队列本身已满的状态，因此新用户甚至无法加入队列，被要求稍后重试。它不同于单纯的*繁忙*（所有计算资源被占，但队列仍有等待空间）。
