其实 2026 年的开源 TTS 早就打平甚至局部反超闭源了

整理了目前最能打的 10 个开源 TTS 仓库，从 CPU 极速跑到 3 秒克隆、双人播客全覆盖 👇

1. Qwen3-TTS（阿里通义）

Apache 2.0 可商用 全能旗舰。3 秒零样本克隆，支持自然语言直接“捏”音色和情绪，超低延迟流式输出，中英日韩多语种极稳。

2. CosyVoice（阿里 FunAudioLLM）

Apache 2.0 可商用 跨语种克隆天花板。拿一段中文样本就能直接说地道英文/日文，还支持各种方言口音，出海本地化配音神器。

3. Kokoro

Apache 2.0 可商用 仅 82M 参数的小钢炮！不需要显卡，普通廉价 CPU 服务器就能狂飙，英文音质惊艳，批量跑旁白最省钱。

4. Chatterbox（Resemble AI）

MIT 可商用 支持 23+ 语种克隆，主打“情感夸张度调节”和超低延迟（75–100ms），跑欧美独立站 UGC 广告配音极其自然。

5. IndexTTS（B站） 短视频剪辑刚需

最大杀手锏是情感解耦 + 精准时长控制，音画卡点严丝合缝，做短剧和混剪配音太省心了。

6. Dia（Nari Labs）

Apache 2.0 可商用 专为双人对话/播客而生。剧本里写 [S1] [S2] 一口气生成双人对话，原生带 (laughs) 笑声和停顿，做海外情景剧广告绝了。

7. Fish Speech 小语种之王

覆盖 80+ 种语言，支持自然语言风格控制，测冷门小语种市场非常好用

8. F5-TTS 基于 Flow Matching 架构

语流极度丝滑不卡顿，零样本音色还原度很高，社区一键包满大街都是。

9. GPT-SoVITS 老牌声音克隆王者

几分钟音频微调后相似度拉满，适合打造自己账号或虚拟人的固定专属 IP 音色。

10. ChatTTS 

主打日常闲聊口语感，自带呼吸、停顿和笑声，不像播音腔（非商用协议，适合日常玩和测试）
