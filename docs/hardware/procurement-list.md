## §1 使用说明

**三条必读：**

1. **价格是快照，不是承诺。** 所有价格来自 2026-10-22 的电商/行情检索。2026 年 GPU 与内存价格波动剧烈
   （5060 Ti 16G 挂牌价已达 MSRP 的 167%；DGX Spark 半年内从 $3999 涨到 $6950），
   **下单前必须复核**，并以"区间"而非单一数字作为预算依据。
2. **置信标注规则**：
   - `已核实商品页`——检索到具体 SKU 的可下单页面（含价）；
   - `仅检索式链接`——只拿到行情区间或聚合报价，未定位到可下单 SKU。
   两种标注都**不代表已验货**，只代表信息可追溯。
3. **商品与价格只出现在本文与 [README.md](./README.md)。** `plan-1`~`plan-6` 提到硬件时只写 `D-xx` 编号。

**路数读法（最容易被误读的一点）：**

```
单盒路数 = min( 槽位约束, 吞吐约束 )
槽位约束 = floor( 可用显存GB × 0.85 ÷ 4.6 )
同机含 LLM 时：可用显存 = 标称 − LLM权重 − KV − 0.8GB 余量
```

- 表中 `2 / 1 / 1` 表示"纯管线盒 / 同机加 LLM 后 / 同机加更小 LLM 后"，逐条算式见 §4。
- **同机跑 LLM 后单盒普遍只剩 1 路**——这是全部方案的共同结论。
- DGX Spark / Jetson / Ryzen AI Max 的路数是**槽位上限**，带宽会成为更早到来的瓶颈，不得省略"槽位"二字。

## §4 条目详情（路数逐条给算式）

### D-G01 RTX 3060 12G

```
纯管线：floor(12 × 0.85 ÷ 4.6) = floor(2.22) = 2 路
+②8B Q4/KV8K：可用 = 12 − 5.0 − 0.6 − 0.8 = 5.6 → floor(5.6×0.85÷4.6) = floor(1.03) = 1 路
+③9B Q4/KV8K：可用 = 12 − 5.7 − 0.7 − 0.8 = 4.8 → floor(4.8×0.85÷4.6) = floor(0.89) = 0 路  ← 装不下
+④4B Q4/KV8K：可用 = 12 − 2.6 − 0.4 − 0.8 = 8.2 → floor(1.51) = 1 路
+⑥0.8B Q4/KV8K：可用 = 12 − 0.6 − 0.2 − 0.8 = 10.4 → floor(1.92) = 1 路
```

- 定位：**最低成本跑通验证**。二手 1,400–1,600 元，适合先验证链路再决定扩容。
- 风险：二手多为矿卡/翻新，无保修；2026-06 复产批次与存量二手混售，需验 SN；带宽 360 GB/s 是 50 系的 1/2。
- 关键结论：**这张卡跑不了 9B**（可用显存 < 单路管线的 4.6GB）。

### D-G02 RTX 4060 Ti 16G

```
纯管线：floor(16 × 0.85 ÷ 4.6) = floor(2.96) = 2 路
+②8B Q4/KV8K：可用 = 16 − 5.0 − 0.6 − 0.8 = 9.6 → floor(1.77) = 1 路
+③9B Q4/KV8K：可用 = 16 − 5.7 − 0.7 − 0.8 = 8.8 → floor(1.63) = 1 路
+④4B Q4/KV8K：可用 = 16 − 2.6 − 0.4 − 0.8 = 12.2 → floor(2.25) = 2 路
+⑤2B Q4/KV8K：可用 = 16 − 1.3 − 0.3 − 0.8 = 13.6 → floor(2.51) = 2 路
```

- 定位：**最便宜的 16G**，是"显存够、带宽不够"的典型。
- 风险：**128bit / 288 GB/s** 是本档最大短板——本地 LLM token/s 只有 5070 Ti 的 1/3；已停产，靠库存。
- 算式揭示：16G 的四个本地档里，只有 4B 及以下能做到"同机 2 路"。

### D-G03 RTX 5060 Ti 16G

```
同 D-G02（显存同为 16G）：纯管线 2 路；+②8B 1 路；+③9B 1 路；+④4B 2 路；+⑤2B 2 路
```

- 定位：**D-G05 缺货时的替代**，不建议作为首选。
- 风险：挂牌价 5,999 元 = MSRP 3,599 的 **167%**，溢价期买入不划算；128bit 位宽同样限制长上下文的解码速度。
- 与 D-G02 的差别只在带宽（448 vs 288 GB/s）与架构，价差 2,000–2,600 元。

### D-G04 RTX 5070 12G

```
纯管线：floor(12 × 0.85 ÷ 4.6) = 2 路
+④4B Q4/KV8K：可用 = 12 − 2.6 − 0.4 − 0.8 = 8.2 → floor(1.51) = 1 路    ← 本机实测口径
+⑤2B Q4/KV8K：可用 = 12 − 1.3 − 0.3 − 0.8 = 9.6 → floor(1.77) = 1 路
+⑥0.8B Q4/KV8K：可用 = 12 − 0.6 − 0.2 − 0.8 = 10.4 → floor(1.92) = 1 路
```

- 定位：**方案①纯管线盒的首选**。带宽 672 GB/s 是 12G 档最高，STT/TTS 独占 GPU。
- 风险：12GB 是硬约束——**同机任何 LLM 都只能 1 路**，要并发必须拆盒（走 §5 均衡/高并发套餐）。
- 与 D-G05 的决策线：价差 1,000–2,700 元。若买 5070 只作纯管线盒，D-G04 更划算；若想"一盒兼跑 LLM + 2 路管线"，必须 D-G05。

### D-G05 RTX 5070 Ti 16G

```
纯管线：floor(16 × 0.85 ÷ 4.6) = 2 路
+②8B Q4/KV8K：可用 = 16 − 5.0 − 0.6 − 0.8 = 9.6 → floor(1.77) = 1 路
+③9B Q4/KV8K：可用 = 16 − 5.7 − 0.7 − 0.8 = 8.8 → floor(1.63) = 1 路
+④4B Q4/KV8K：可用 = 16 − 2.6 − 0.4 − 0.8 = 12.2 → floor(2.25) = 2 路
```

- 定位：**方案②的入门推荐**，也是 16G 档唯一能让 4B "同机 2 路"的卡。
- 风险：16G 跑 9B Q8（9.8GB）后只剩 1 路，**Q8 与多路不可兼得**；300W + 三槽需 750W 电源。
- 本机同型号（Laptop 版）实测：S2S + 4B Q4 同卡 = 11,878 MiB / 12,227 MiB，余量约 0 —— 桌面版 16G 会宽裕，但仍是"1 路 + LLM"的上限。

### D-G08 DGX Spark 128GB

```
模型可用内存 ≈ 120GB（系统预留 8GB）
纯管线：floor(120 × 0.85 ÷ 4.6) = floor(22.17) = 22 路（槽位上限）
+②8B Q4/KV8K：可用 = 120 − 5.0 − 0.6 − 0.8 = 113.6 → floor(20.99) = 20 路（槽位上限）
+③9B Q4/KV8K：可用 = 120 − 5.7 − 0.7 − 0.8 = 112.8 → floor(20.84) = 20 路（槽位上限）
+⑥0.8B Q4/KV8K：可用 = 120 − 0.6 − 0.2 − 0.8 = 118.4 → floor(21.88) = 21 路（槽位上限）
```

- 定位：**PoC 候选（待验证）**。唯一"一台机器同时是 LLM 盒 + 管线盒且内存充裕"的形态，可承载 27B 级模型。
- 风险（三条并列，任一都可能否决）：
  1. **ARM64**——现有镜像与 `cache/` 是 x86_64，需重建 arm64 镜像（不改 `src/`，但工作量未评估）；

  3. 内存焊死不可扩，扩容 = 再买一台；价格半年涨 74% 且仍在涨。
- 采购方式：**先买 1 台实测 T4/T5，通过后再谈批量**。

### D-S01 NVIDIA L20 48G

```
纯管线：floor(48 × 0.85 ÷ 4.6) = floor(8.87) = 8 路
+②8B Q4/KV8K：可用 = 48 − 5.0 − 0.6 − 0.8 = 41.6 → floor(7.69) = 7 路
+③9B Q4/KV8K：可用 = 48 − 5.7 − 0.7 − 0.8 = 40.8 → floor(7.54) = 7 路

+③9B FP16/KV8K：可用 = 48 − 18 − 0.7 − 0.8 = 28.5 → floor(5.27) = 5 路
```

- 关键优势：48G 可以跑 **9B FP16（5 路）**——这是全表唯一能"FP16 质量 + 多路"的组合。


- 定位：**需要台式机箱时的 L20 替代**（带涡轮风扇，不需要服务器风道）。
- 风险：**价格区间跨度 1.5 万元（29,316–44,199）**，渠道极不透明，必须逐家比价并确认含票含保；无官方零售渠道，多为代理工包；涡轮噪音高，不适合开放办公区。
- 决策线：与 D-S01 同显存同带宽量级，但贵 1–2 万元。**除非必须上台式机箱，否则选 D-S01。**

### D-E01 Jetson Orin NX 16G（PoC 候选）

```
可用内存 ≈ 12GB（JetPack/Ubuntu + CUDA 运行时占 3–4GB）
纯管线：floor(12 × 0.85 ÷ 4.6) = floor(2.22) = 2 路（槽位上限）
+④4B Q4/KV8K：可用 = 12 − 2.6 − 0.4 − 0.8 = 8.2 → floor(1.51) = 1 路（槽位上限）
+⑥0.8B Q4/KV8K：可用 = 12 − 0.6 − 0.2 − 0.8 = 10.4 → floor(1.92) = 1 路（槽位上限）
+③9B Q4/KV8K：可用 = 12 − 5.7 − 0.7 − 0.8 = 4.8 → floor(0.89) = 0 路  ← 装不下
```

- 定位：**低功耗 PoC**（15–40W）。已证实可跑 Qwen3-ASR **0.6B int4 + Qwen3-TTS CustomVoice int4**（Seeed 方案），
  但**没有 1.7B + transformers 的实测**——本清单收录它是为了"买 1 台验证"，不是为直接量产。
- 风险：102 GB/s 带宽下 **RTF 可能 >1（不实时）**；需重建 arm64 镜像；模组需自配载板；Jetson 全系 2026-07 涨价 49–101%。

### D-E02 Jetson AGX Orin 64G（PoC 候选）

```
可用内存 ≈ 60GB（系统预留约 4GB）
纯管线：floor(60 × 0.85 ÷ 4.6) = floor(11.09) = 11 路（槽位上限）
+②8B Q4/KV8K：可用 = 60 − 5.0 − 0.6 − 0.8 = 53.6 → floor(9.90) = 9 路（槽位上限）
+③9B Q4/KV8K：可用 = 60 − 5.7 − 0.7 − 0.8 = 52.8 → floor(9.76) = 9 路（槽位上限）
```

- 定位：**边缘盒里唯一内存宽裕到"可能跑通 1.7B 双模型"的档位**。204.8 GB/s 带宽也优于 Orin NX 两倍。
- 风险：模组 **$2999**（2026-07 涨价 88%，原 $1599）+ 载板，整机逼近 D-G06 4090；同样需 arm64 镜像；1.7B 实测仍缺失。

### D-E09 AMD Ryzen AI Max+ 395（PoC 候选）

```
显存按可分配 96GB 计（128GB 统一内存）
纯管线：floor(96 × 0.85 ÷ 4.6) = floor(17.74) = 17 路（槽位上限）
+③9B Q4/KV8K：可用 = 96 − 5.7 − 0.7 − 0.8 = 88.8 → floor(16.41) = 16 路（槽位上限）
+⑥0.8B Q4/KV8K：可用 = 96 − 0.6 − 0.2 − 0.8 = 94.4 → floor(17.44) = 17 路（槽位上限）
```

- 定位：**x86_64 + 大统一内存**路线。不需要重建 arm64 镜像，LocalAI 兼容表把 Qwen3-TTS 列在 ROCm 上。
- 风险：ROCm 对 transformers 自定义 attention 的覆盖是唯一不确定点；128GB 统一内存**焊死不可扩**；`4.6GB/路` 是 CUDA 实测值，**跨到 ROCm 不可直接外推**。

## §5 多盒组合套餐

> 网络前提：语音流是 16kHz / PCM16 / 单声道 ≈ **256 kbps/路**，20 路合计约 5 Mbps；
> LLM 侧是纯文本，量级更低。**1GbE 足够，10GbE 非必需**（理由与拓扑见
> [deployment-multibox.md](./deployment-multibox.md)）。

### 套餐 A：入门（远程 LLM）

| 项 | 配置 | 数量 | 单价（元） | 小计 |
|---|---|---|---|---|
| 管线盒 | **D-G04** RTX 5070 12G 整机 | 1 | 12,000–13,500 | 12,000–13,500 |
| LLM | 远程 GPUStack（现有 192.168.40.30） | — | 0 | 0 |
| 网络 | 现有千兆 | — | 0 | 0 |
| **合计** | | | | **12,000–13,500** |

- 可达路数：**2 路**（纯管线，`floor(12×0.85÷4.6)=2`）。
- 适合：现有 GPUStack 可用、要求数据本机、并发 ≤2 的试点。
- 扩容路径：再加一台 D-G04 → 4 路，线性叠加，无需换交换机。

### 套餐 B：均衡（本地 9B/8B + 管线盒阵列）

| 项 | 配置 | 数量 | 单价（元） | 小计 |
|---|---|---|---|---|
| LLM 盒 | **D-G06** RTX 4090 24G 整机 | 1 | 12,000–18,000 | 12,000–18,000 |
| 管线盒 | **D-G02** RTX 4060 Ti 16G 整机 | 2–4 | 6,800–8,000 | 13,600–32,000 |
| 网络 | 千兆交换机（现有） | — | 0 | 0 |
| **合计** | | | | **25,600–50,000** |

- 可达路数：
  - LLM 盒自身：**3 路**（`可用=24−5.7−0.7−0.8=16.8 → floor(3.10)`）
  - 2 台管线盒：2×2 = **4 路**
  - 合计 **7 路**（2 台管线盒）～ **11 路**（4 台管线盒）
- 适合：数据不出内网 + 中等并发。
- 注意：D-G02 的 288 GB/s 只影响其自身若兼跑 LLM 的表现；作纯管线盒时带宽不构成瓶颈。

### 套餐 C：高并发（48G 级 LLM 盒 + 管线盒阵列）

| 项 | 配置 | 数量 | 单价（元） | 小计 |
|---|---|---|---|---|
| LLM 盒 | **D-S01** L20 48G + 服务器整机 | 1 | 25,000–42,000 | 25,000–42,000 |
| 管线盒 | **D-G04** RTX 5070 12G 整机 | 4–8 | 12,000–13,500 | 48,000–108,000 |
| 网络 | 千兆（20 路约 5 Mbps，无需 10GbE） | — | 0 | 0 |
| **合计** | | | | **73,000–150,000** |

- 可达路数：
  - LLM 盒：**7 路**（`可用=48−5.7−0.7−0.8=40.8 → floor(7.54)`）
  - 4 台管线盒：8 路；8 台：16 路
  - 合计 **15–23 路**
- 适合：20 路档位的正式部署。
- 替代：LLM 盒换 **D-G07**（5090 32G，4 路）可省 1–2 万元但路数减半；
  **D-S02**（5880 Ada）只在必须台式机箱且无服务器机柜时选。

### 套餐 D：边缘 PoC（单点低功耗，待验证）

| 项 | 配置 | 数量 | 单价（元） | 小计 |
|---|---|---|---|---|
| 边缘盒 | **D-E01** Jetson Orin NX 16G 整机 | 1 | 19,500–21,500 | 19,500–21,500 |
| LLM | 远程 GPUStack | — | 0 | 0 |
| **合计** | | | | **19,500–21,500** |

- 可达路数：**槽位上限 2 路**，实际受 102 GB/s 带宽限制，**必须先测 T3/T5**。
- 目的：验证"ARM 边缘盒 + 一致模型"这条路走不走得通，**不是为量产**。
- 若 T3 实测 RTF >1，则该路线整体否决，转 D-G04/D-G05。

## §7 采购前必做的三件事

1. **核对型号后缀**：`5090 32G` vs `5090D v2 24G`、`Atlas 500 型号3000(8G)` vs `Atlas 500 A2(12G)`——
   本轮检索中这两组是最容易买错的地方。
2. **让供应商书面确认功耗与散热**：L20 的 275W/350W 两说、5880 Ada 的工包保修、DGX Spark 的 OEM 配置差异。
3. **到货即按 [acceptance-test-plan.md](./acceptance-test-plan.md) 跑 T0~T9**，判定线见
   [performance-assumptions.md](./performance-assumptions.md) §5。任何"纸面可行"未经 T3/T4 实测都不能视为通过。
