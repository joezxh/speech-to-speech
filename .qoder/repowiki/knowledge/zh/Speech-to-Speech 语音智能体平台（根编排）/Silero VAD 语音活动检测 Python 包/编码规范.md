- 可选第三方库（onnxruntime、numpy、torchaudio、torchcodec）采用运行时 `try/except ImportError` 懒加载，避免在非必要场景引入依赖。
- 音频解码在 torchaudio 与 torchcodec 之间自动回退，并在两者均缺失时抛出包含安装命令的统一错误消息。
- ONNX Runtime Session 统一设置 `inter_op_num_threads=1`、`intra_op_num_threads=1`，并通过 `CPUExecutionProvider` 强制 CPU 执行以隔离线程。
- 采样率处理遵循 8000/16000 双速率约定，对高于 16k 且为其倍率的输入通过步长抽取降采样到 16k。
- 包内资源（预训练模型）通过 `importlib.resources.files(package_path).joinpath(...)` 访问，兼容 `importlib_resources` 与标准库 `importlib.resources`。
