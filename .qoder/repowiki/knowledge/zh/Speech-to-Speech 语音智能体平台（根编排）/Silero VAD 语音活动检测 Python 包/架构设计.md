包以 `src/silero_vad/` 为源码根，通过 `pyproject.toml`（hatchling 构建）发布为 `silero-vad`。

- 入口层：`__init__.py` 仅暴露 `load_silero_vad`、`VADIterator`、`get_speech_timestamps` 等公共 API；`sequence_vad` 模块通过 PEP 562 的 `__getattr__` 延迟导入，避免在缺少 onnxruntime/numpy 时失败。
- 模型加载层：`model.py::load_silero_vad` 根据 `onnx`/`sequence`/`opset_version` 参数在 JIT (`silero_vad.jit`)、ONNX (`OnnxWrapper`)、Sequence ONNX (`SileroVADSequence`) 三者间分派，并通过 `importlib.resources` 从 `silero_vad.data` 包内读取预训练权重。
- 推理后端：
  - `utils_vad.OnnxWrapper`：流式 ONNX 包装器，维护 LSTM state/context，按帧切片调用 ONNX Runtime。
  - `sequence_vad.SileroVADSequence`：批量化 ONNX 前端，将最多 512 帧拼接成一次 ONNX 调用，绕过逐帧 Python 循环以提升多线程吞吐。
  - TorchScript 路径由 `init_jit_model` 直接加载 `.jit` 文件。
- 音频 I/O：`utils_vad.read_audio/save_audio` 通过 `_try_import_torchaudio` / `_decode_with_torchcodec` 在 torchaudio 与 torchcodec 之间回退，缺失时抛出明确提示安装 `[audio]` 或 `[codec]` extra。
- 数据目录 `data/` 内嵌多种格式模型（`.jit`、`.onnx`、`.safetensors`、OpenVINO），由 `load_silero_vad` 按需选择。
- 测试位于 `tests/`，使用 pytest；调参与阈值搜索在 `tuning/` 中独立实现。
- `examples/` 下按语言/框架组织 C++、C#、Go、Haskell、Java、Rust 等绑定示例，作为外部集成参考而非包的一部分。
