模块由三个入口脚本组成，职责分层清晰：
- `main.js` 是浏览器端主 UI 控制器，负责状态机（idle/connecting/listening/user-speaking/processing/ai-speaking/error）、localStorage 配置持久化、摄像头快照、Web Search / Camera Snapshot 工具注册与执行、以及通过 `S2sRealtimeClient` 驱动会话。
- `s2s-realtime-client.js` 导出 `S2sRealtimeClient extends EventTarget`，封装 OpenAI Agents SDK 的 `RealtimeSession`，在构造函数中根据 `transport` 选择 `OpenAIRealtimeWebSocket` 或 `OpenAIRealtimeWebRTC`；WebSocket 路径通过 AudioWorklet (`mic-capture.js` / `audio-playback.js`) 完成 PCM 采样率对齐与缓冲播放，WebRTC 路径直接走 MediaStream + `<audio>`；同时维护本地 VAD、噪声门、回放队列、用户音频录制与转录增量拼接。
- `turn-latency.js` 仅暴露 `readTurnLatency(response)`，从 `speech_to_speech.turn_latency` metadata 中解析并校验端到端延迟指标，供客户端在 `response.done` 时消费。
依赖方向单向：`main.js` → `s2s-realtime-client.js` → `turn-latency.js`，UI 层不直接访问 SDK。
