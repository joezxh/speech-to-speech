模块由两个并列的单页 HTML 组成，彼此独立、无共享 JS 逻辑：
- `demo/index.html` 是用户侧的主对话界面，通过 `<script type="module" src="main.js">` 加载业务逻辑，依赖 `style.css` 定义 orb/状态机/动画等视觉样式，并引入 `vendor/openai-realtime-agents.umd.js` 作为第三方运行时。
- `demo/console.html` 是运维控制台，通过 `<script type="module" src="ui/console/app.js">` 加载配置编辑、会话热更新、版本回滚、实例与审计等面板，样式由独立的 `console.css` 提供。
两页共享同一套暗色配色变量（--bg / --accent / --text 等）但 CSS 文件互不引用，保证 UI 风格一致且可独立维护；HTML 结构以语义化 `<dialog>`、`<section data-panel>`、`<nav role="tablist">` 组织，JS 通过 DOM 属性（如 `data-tab`、`data-panel`、`aria-selected`）驱动视图切换。
