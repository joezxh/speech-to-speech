demo 目录以 server.py 为唯一进程入口：FastAPI 同时承担静态文件服务器（mount index.html/main.js/ws/ui/worklets 等）、OpenAI Realtime Agents SDK UMD 包与 VAD 资源的 /vendor 代理，以及业务 API 网关。
- python_backend 暴露的 /api/config 是前后端契约的单一来源：浏览器据此在三种部署模式间切换——SPEECH_TO_SPEECH_URL 直连、LOAD_BALANCER_URL 走 /api/session 代理、或 allowDirect 让用户自行输入 s2s URL；WebRTC 仅在直连模式下由 /api/calls 转发 SDP offer。
- node_runtime 通过 S2sRealtimeClient 封装 OpenAI Agents SDK，根据 config 选择 ws 或 webrtc 传输，并在 LB 模式下维护 queue ticket、heartbeat 与会话配额心跳，与 limiter/auth 状态双向同步。
- console_ui 作为独立 HTML 入口，复用 param_platform 的 store/renderer/publish_flow 对参数平台进行 CRUD，并通过 server.py 中 param_api.install(app) 挂载到同一个 FastAPI 实例。
- 所有敏感凭据（Serper key、LB_HF_TOKEN、LOAD_BALANCER_URL）仅驻留服务端，浏览器只拿到非敏感的 rtc/iceServers/startupGreeting 配置。
