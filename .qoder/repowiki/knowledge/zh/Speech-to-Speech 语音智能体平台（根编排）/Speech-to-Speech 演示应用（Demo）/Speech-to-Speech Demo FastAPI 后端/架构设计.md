模块由四个互相协作的 Python 文件组成，围绕一个 FastAPI `app` 装配：
- `server.py` 是应用入口，负责环境变量驱动的模式切换（直连 s2s / 经 LB 代理）、注册 `/api/*` 路由、静态前端挂载，并在启动时初始化 `param_api`、`limiter` 和后台 sweep 任务。
- `auth.py` 通过 `huggingface_hub.attach_huggingface_oauth` 注入 HF OAuth，提供 `resolve_identity`（返回 tier + limiter keys + anon cookie）和 `user_view`，将登录态映射为匿名/pro/free/org 四档身份。
- `limiter.py` 是纯函数式配额引擎，使用 SQLite（WAL 模式）持久化 `usage_daily`/`sessions`/`search_daily` 三张表，实现按日预算、分块预留、心跳续租、崩溃回收（sweep）以及对匿名用户的 IP+cookie OR 匹配。
- `param_api.py` 独立挂载到 `/admin` 路由，实现 spec §13 附录 A.1–A.7 的参数目录、草稿、发布、回滚、热更新、版本审计与实例视图，通过 `install(app)` 暴露给 server。
依赖方向单向：`server → auth + limiter + param_api`；`auth` 仅调用 `limiter.hash_key/sign_cookie/verify_cookie`，不反向依赖 server；`param_api` 完全独立于 demo 业务逻辑，只依赖 `param_platform`。外部边界包括 Serper.dev、HF Ingress LB、Hugging Face whoami-v2 与本地 SQLite。
