- 后端路由通过 `core/router_registry.register_api_routers` 集中注册，而非在 `main.py` 中逐个 `include_router`，保持路由发现统一。
- 服务层以独立模块暴露（如 `services/voice_service.py`、`services/publish_flow_service.py`），并在 `services/__init__.py` 中按需 re-export，供 routers 与 lifespan 直接 import。
- 数据库访问采用 repository 模式：每个领域实体（draft、version、audit、voice、turn_latency、user）有对应的 `*_repository.py`，ORM 模型集中在 `models/`，并通过 `db/base.py` 的 Base 类派生。
- 配置通过 `app/config/_*.py` 中的 pydantic-settings 分组对象（app/console/auth/demo/database）加载 `.env`，环境变量名不区分大小写。
- 前端 API 调用按资源拆分到 `src/api/*.ts`，并由 `stores/` 中的 Pinia store 组合调用，视图层不直接发起网络请求。
- 测试按 `tests/unit/`（纯函数/服务）与 `tests/integration/`（httpx TestClient 端到端）两层组织，fixture 放在 `tests/fixtures/`。
