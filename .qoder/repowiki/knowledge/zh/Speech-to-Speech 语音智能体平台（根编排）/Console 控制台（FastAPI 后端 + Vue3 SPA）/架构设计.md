模块由三个子目录组成：
- `backend/app`：FastAPI 应用，按职责分层——`routers/`（含 `demo/` 子路由）定义 HTTP/WebSocket 端点，`services/` 封装业务逻辑（voice、catalog、publish_flow、turn_latency_indexer、supervisor_client、instance_monitor 等），`repositories/` 通过 SQLAlchemy 2.x + Alembic 访问 SQLite/PostgreSQL，`models/` 声明 ORM 模型，`schemas/` 用 Pydantic v2 描述请求/响应体，`config/` 用 pydantic-settings 分组加载 JWT、数据库、console、demo 等配置，`core/` 提供 SPA 挂载、路由注册、错误处理与安全中间件，`middleware/` 注入 RequestId 与安全头。
- `frontend/src`：Vue 3 + TypeScript + Pinia + ant-design-vue，`views/` 对应控制台各页面（Params/Versions/Audit/Sessions/Voices），`features/voice/` 是独立的对话页功能域（WebRTC 音频采集、VAD、S2S WebSocket 传输、turn-latency 统计），`stores/` 为全局状态，`api/` 按资源划分 axios 客户端，`components/` 为共享 UI 组件。
- `deploy/`：supervisord.conf 启动 `console`（uvicorn app.main:app :8000）与 `pipeline`（127.0.0.1:8765），console 将 `/v1/realtime` 反向代理到 pipeline；SPA 由 FastAPI 直接静态托管于 `/` 与 `/console`。
依赖方向：routers → services → repositories → models；frontend 仅通过 REST/WS 与 backend 通信，无直接耦合。
