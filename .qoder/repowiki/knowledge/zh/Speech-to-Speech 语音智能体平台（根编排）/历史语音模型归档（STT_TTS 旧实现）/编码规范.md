- Handler 统一继承 `speech_to_speech.baseHandler.BaseHandler` 并实现 `setup` / `warmup` / `process` 三段式生命周期，warmup 中用 dummy 输入预热模型并记录耗时。
- TTS handler 在 `process` 中对音频分块做 `librosa.resample(..., target_sr=16000)` 后乘以 32768 转为 `np.int16`，再按 `blocksize` 切片 yield 给上层。
- 语言到模型方言/说话人的映射集中放在模块级字典常量（如 `WHISPER_LANGUAGE_TO_MELO_LANGUAGE`、`WHISPER_LANGUAGE_TO_PARLER_SPEAKER`），避免硬编码散落在逻辑中。
- CLI 可配置参数以 `@dataclass` + `field(metadata={'help': ...})` 形式声明，与 handler 一一对应存放于 `arguments_classes/`。
- 长耗时推理通过 `threading.Thread` 或 streamer 异步执行，主协程从 streamer 消费音频片段，并在每次迭代检查 `cancel_response.is_set()` / `cancel_scope.is_stale` 实现中断。
