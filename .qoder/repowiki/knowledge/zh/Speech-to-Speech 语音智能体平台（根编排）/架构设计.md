根目录承担发布与编排职责，将多个子模块装配为单一可分发包：
- `pyproject.toml` 通过 setuptools 从 `src/speech_to_speech*` 发现包，声明核心依赖与可选 extras（chattts/faster-whisper/kokoro/webrtc 等），并暴露 `speech-to-speech` CLI 入口；所有子模块最终都作为该包的子包被消费。
- `demo_app` 是 FastAPI 应用，承载 WebRTC、负载均衡器代理与 HF OAuth 计费，对外提供 `/api/*` 路由，内部调用 `core_library` 的注册表驱动流水线。
- `core_library` 提供后端注册表与 YAML 配置加载，是 demo_app、tests、scripts_and_examples 共同依赖的运行时骨架。
- `silero_vad_vendor` 作为独立 vendored Python 包随主包一起分发，供 core_library 中的 VAD 组件使用。
- `archive` 保留旧实现供回溯，不参与当前运行期。
- `docs` 与 `scripts_and_examples` 分别承担用户文档与基准/压测工具，由 tests 覆盖。
- 顶层 `llm-proxy.py` 是在 WSL2 宿主机上运行的轻量 HTTP 反向代理，用于绕过 NAT 把容器内的 LLM 请求转发到外部 GPUStack，配合 `.env.gpustack` 与 `docker-compose.gpustack.yml` 使用。
- 多套 Dockerfile（cu128/cu130/arm64/baked/local/sox/torch-base）与 docker-compose.*.yml 组合出本地开发、GPUStack 部署、HF Space 打包等不同运行环境。
