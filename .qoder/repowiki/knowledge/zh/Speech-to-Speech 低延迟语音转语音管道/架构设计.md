根模块以 `src/speech_to_speech` 为 Python 包核心，按职责拆分为 LLM、STT、TTS、VAD、pipeline、api/openai_realtime、arguments_classes、utils 等子模块；各子模块通过统一的基类（如 baseHandler、base_stt_handler）和 `backend_registry.py` 注册机制实现后端热插拔，由 `s2s_pipeline.py` 在运行时组装成处理链。`api/openai_realtime` 提供 FastAPI + WebRTC/WebSocket 服务器，复用 pipeline 与 VAD/LLM 组件对外暴露 OpenAI 兼容接口。顶层 `demo/` 基于该 API 构建浏览器+FastAPI 演示，`scripts/` 与 `examples/` 提供基准测试与示例调用，`tests/` 覆盖所有子模块，CI/Publish 工作流统一驱动构建与发布。
