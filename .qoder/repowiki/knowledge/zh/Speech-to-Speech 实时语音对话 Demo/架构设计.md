模块采用前后端分离的单容器部署：Python FastAPI (`server.py`) 同时托管静态前端文件并暴露 `/api/*` 代理路由（搜索、会话握手、队列、心跳、WebRTC SDP 转发），通过环境变量 `LOAD_BALANCER_URL`/`SPEECH_TO_SPEECH_URL`/`SERPER_API_KEY` 切换直连或负载均衡模式；Node.js 前端 (`main.js`) 作为入口，组合 `ui/`（DOM 视图、聊天面板、账户 UI）、`ws/`（音频录制、FFT 可视化、编解码）和 `worklets/`（音频播放/麦克风采集 Web Worker）实现录音、噪声门限、摄像头快照等交互，并通过 `s2s-realtime-client.js` 封装官方 `@openai/agents` SDK 的 `RealtimeSession`，统一 WebSocket 与 WebRTC 两种传输；Dockerfile 使用多阶段构建将 `@openai/agents-realtime` 的 UMD bundle 预编译进镜像，由 uvicorn 启动 FastAPI 应用监听 7860 端口。依赖方向单向：`main.js` → `s2s-realtime-client.js` → `ws/*` + `ui/*`，后端仅通过 HTTP 与外部 LB/Serper 通信，不反向依赖前端。
