- 每个脚本通过 `argparse` 定义 CLI 参数并以 `if __name__ == "__main__": main()` 作为入口。
- 基准脚本采用统一的 `BenchmarkResult` 类封装单次处理器的多次迭代结果，并通过 `get_stats()` 输出含均值/方差/最小最大值的字典。
- Handler 实例化采用字符串名称到模块的映射（`if/elif handler_name == ...` 分支 + `from speech_to_speech.* import *` 延迟导入），避免启动时加载所有后端。
- 所有处理器统一通过 `stop_event + Queue(queue_in, queue_out)` 构造，并以 `handler.process(input_obj)` 迭代器消费输出，便于统一计时与异常捕获。
- 基准结果最终序列化为包含 `results` 列表与 `timestamp` 的 JSON 文件，便于后续横向对比分析。
- 实时客户端使用协程函数 (`async def`) 组织单客户端流程，并通过 `asyncio.gather` 并发启动 N 个客户端实现并行压测。
