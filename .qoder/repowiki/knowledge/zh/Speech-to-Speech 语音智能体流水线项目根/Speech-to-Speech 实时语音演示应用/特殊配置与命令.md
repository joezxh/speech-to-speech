本地启动需先 `uv sync --python 3.11 && uv run speech-to-speech serve` 启动后端，再 `npm ci --prefix demo && uv pip install -r demo/requirements.txt` 安装 demo 依赖，设置 `SPEECH_TO_SPEECH_URL=ws://localhost:8765/v1/realtime` 后 `uv run uvicorn --app-dir demo server:app --reload --port 7860`；Docker 构建用 `docker build -t s2s-demo demo/`，运行需 `-e SPEECH_TO_SPEECH_URL=ws://host.docker.internal:8765/v1/realtime`。测试命令：`npm run test:agents`（adapter/ws/webrtc）与 `npm run test:ui`（Playwright Chromium）。
