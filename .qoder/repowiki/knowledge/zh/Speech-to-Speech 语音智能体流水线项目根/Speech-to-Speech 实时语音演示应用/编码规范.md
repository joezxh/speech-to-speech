- HTTP 处理器统一使用同步 `def` 而非 `async def`，阻塞操作（Compose、pool probe、publish）通过 `starlette.concurrency.run_in_threadpool` 或 `asyncio.to_thread` 调度，避免阻塞 FastAPI 事件循环。
- 所有对外部服务（Serper、LB、s2s calls、whoami-v2）的网络调用都包裹在 `try/except httpx.RequestError` 中，并返回带人类可读 `detail` 的 502/404，错误日志通过 `_log_load_balancer_failure` 过滤敏感 header。
- 管理员 API 通过 `_guard(request, write=...)` 解析 Bearer token，区分 `admin` 与 `operator` 角色，写端点额外用 `_require_admin` 校验，并以 constant-time `secrets.compare_digest` 比较 token。
- 敏感字段按名称后缀匹配（`api_key|_key|token|secret|password`）被 `_mask` 替换为 `***`，确保 draft 返回与 FlowError message 均不泄露凭据。
- 配置项一律从 `os.environ.get(...)` 读取并在模块顶层计算派生值（如 `LIMITER_ENABLED`、`RTC_ICE_SERVERS`、`STARTUP_GREETING`），路由函数内不再重复解析。
- 前端状态与 UI 分离：`ui/dom.js` 暴露 `$`/`escHtml` 等纯工具，`ui/chat.js`、`ui/account.js`、`ui/console/app.js` 各自管理一个视图组件，DOM 操作集中在 `dom.js`。
