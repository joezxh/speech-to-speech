本模块是纯脚本/示例集合，不引入运行时依赖，按用途分为三个子目录：
- `scripts/`：独立可执行的 Python CLI，通过 `argparse` + `logging` 暴露命令行接口；`benchmark_stt.py` 与 `benchmark_tts.py` 结构对称，均定义本地 `BenchmarkResult` 类，动态按 handler name 从 `speech_to_speech.STT` / `speech_to_speech.TTS` 导入具体处理器，统一测量 warmup/inference/TTFT/RTF 并输出 JSON；`prepare_eval_space.py` 调用 `huggingface_hub.HfApi` 将源码快照上传到私有 HF Space 以构建 Docker 镜像；`check_pocket_tts_farsi.py` 直接实例化 `PocketTTSHandler` 跑 Farsi 合成用例并校验 G2P 与音频块格式；`synthetic_conversation_realtime_client.py` 基于 `asyncio` + `websockets` + `httpx` 模拟多客户端并发连接 `/v1/realtime`，可选经 LB `/session` 分配计算节点。
- `examples/`：面向打包后的 Realtime 音频客户端的可替换工具实现，每个文件导出 `TOOLS` 声明与 `execute_tool(name, arguments)` 协程，返回 `ToolResult`（来自 `speech_to_speech.api.openai_realtime.audio_client`），当前提供 Serper Google 搜索与 You.com 两种后端；另有 `gemma4-12b-macos/` 与 `streaming-diarization/` 两个自包含 README 示例。
- `example_configs/mac.yaml`：描述性 YAML，声明 vad/stt/llm/tts 四段 pipeline 及 `mac_optimal_settings` 选项，供上层 pipeline 加载器消费。
依赖方向单向指向 `speech_to_speech.*` 内部模块，本模块不被核心代码反向引用。
