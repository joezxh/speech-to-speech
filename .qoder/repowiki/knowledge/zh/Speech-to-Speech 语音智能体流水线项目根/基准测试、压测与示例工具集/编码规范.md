- CLI 脚本统一使用 `argparse.ArgumentParser` 解析参数，并通过 `if __name__ == "__main__": main()` 入口启动。
- 日志通过 `logging.basicConfig(level=logging.INFO, format="%(asctime)s - %(name)s - %(levelname)s - %(message)s")` 初始化，并以 `logger = logging.getLogger(__name__)` 获取 logger。
- 基准脚本在 `benchmark_handler` 内用 `try/except Exception` 包裹单个 handler 的执行，失败时记录错误而非中断其他 handler。
- 结果收集采用本地 `BenchmarkResult` 数据类，通过 `add_inference` / `add_error` 累积指标，再由 `get_stats()` 汇总为字典并 `json.dump` 写出。
- handler 选择通过字符串名称的 `if/elif` 分支在函数体内 `from speech_to_speech.* import ...` 延迟导入，避免未启用后端时的导入开销。
- Realtime 工具示例统一暴露 `TOOLS` 列表（OpenAI function schema）与异步 `execute_tool(name, arguments) -> ToolResult` 函数，作为可插拔后端被主客户端加载。
