该模块为顶层示例集合，不包含可被其他包导入的业务逻辑，仅由两个独立部分组成：`realtime_web_search_tool.py` 是一个独立的异步工具实现，通过 `speech_to_speech.api.openai_realtime.audio_client.ToolResult` 返回结果，对外暴露 `execute_tool(name, arguments)` 函数和声明式 `TOOLS` 列表，供 Realtime 客户端在运行时动态调用；`gemma4-12b-macos/` 子目录仅提供 README 文档，描述如何在 Apple Silicon Mac 上通过 llama.cpp 启动 Gemma 4 12B、用 `uv run speech-to-speech serve` 启动实时语音管线、再用浏览器 demo 或 `speech-to-speech talk` 作为客户端完成麦克风→VAD→LLM→Qwen3-TTS→扬声器的完整闭环。依赖方向单向：示例脚本依赖核心库 `speech_to_speech` 提供的 API，不被核心库反向引用。
